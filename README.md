## 🎮 Overview

SOTFEdit reads and modifies Sons of the Forest save files, allowing you to add items, adjust player stats, teleport, and edit building data outside the game.

Whether you're a newcomer or a veteran, SOTFEdit provides the tools you need to get the most out of your gaming mods experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Item Editor** | Add or remove any inventory item including limited-supply tools |
| **Player Stats** | Set health, energy, hydration, and fullness to any value |
| **Teleport** | Set player and companion spawn coordinates to any location |
| **Building Editor** | Modify placed structure states and material inventories |
